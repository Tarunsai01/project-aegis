Architecture

Four layers, one entry point

Built with FastAPI, Groq, ChromaDB, and Microsoft Presidio. Every request flows through all four before a response is returned.

01

Scrubber

Presidio detects and redacts PII — emails, phone numbers, names — before anything leaves the server.

clean, audit = scrub(raw_prompt)
02

Semantic cache

Embeds the query, checks cosine similarity against past responses. ≥0.85 match returns instantly at $0.

if similarity >= 0.85: return cached
03

Cost router

Token count and complexity flags decide fast / balanced / powerful model tier — no GPT-4 for a status check.

fast: llama-3.1-8b balanced: llama-3.3-70b powerful: gpt-4o
04

Inference

Only reached if the cache misses. Response gets stored back into the cache for the next similar query.

store_in_cache(query, response)
